# 简洁优先的界面约定

CardSpace 的主任务是记录与找回知识。界面优先给内容留空间。

- 默认首页直接展示卡片。搜索框右侧的「搜索」按钮确认查询；页面标题旁的「＋ 新建记忆」为独立、始终可见的主要操作。录入前不要求选择模式、平台、类型、标题与主题。
- 不展示宣传横幅、鼓励性口号、装饰卡片、统计仪表盘、重复面包屑或虚构的个人头像。
- 常用导航为卡片、对话、收藏、参考资料；主题折叠，体检、任务与归档放在“更多”。设置和本地状态留在侧栏底部。模型、持续维护、Agent 与日志设置默认折叠，按需展开。
- 筛选、排序与展示方式收进「视图」。归档直接完成并提供撤销；恢复数据库保留明确确认。技术路径、任务 ID、哈希和模型配置只在相关详情中出现。
- 卡片采用白底与中性文字；列表默认只显示标题、短摘要和来源。详情可直接修改标题、摘要、主题；正文进入聚焦编辑器自动保存。人工修改按字段保护。单个视图只强调一个主要动作。
- 原文、版本、引用在详情中按需查看。DeepSeek 的思考片段默认折叠，并明确区别于最终回答。
- 窄屏优先单列阅读，不通过缩小正文塞入更多内容。
- 开源说明位于设置，许可证和源码下载可访问。主页不增加社区宣传横幅。

修改界面时先问：用户做这件事需要这条信息吗？如果只在排障或设置时需要，请放进对应详情，不要常驻工作台。

具体实现与边界见 [极简交互方案](MINIMAL_INTERACTION_PROPOSAL.md)。
