# V0.4.0 实施记录

日期：2026-10-23。开发分支 `feat/interactive-experiences`；v0.3.0 标签与稳定主线保留。本文件描述代码实施状态，原 BLUEPRINT 是设计基线。

## 已接通

- 固定 Schema 与生成 TS 类型，ContextPack/Plan/预算/授权/诊断/消息契约；受控 TSX 编译 CLI，源码不执行。三类合成 goldens。
- 可信 React 运行时、自有图表与流程组件、有界 Worker；sandbox iframe、CSP、MessageChannel nonce/ref 白名单；状态快照仅在当前浏览器会话保存，重置不调用模型。
- schema 3 迁移前 SQLite 快照；ContextPack/报价/授权/产物/文件不可变；文件与引用哈希、版本 CAS、来源过期检查；v1/v2/v3 备份恢复。
- 本地报价、10 分钟有效期、资料与模型/凭据指纹、human 授权、报价/幂等键去重。通用 compatible 服务明确为 estimated，不提供金额或严格 Token 计费承诺。
- 独立生成通道：计划→代码→编译/验证→至多两次修复。普通队列不领取演示任务；结果不明不自动重发；原始响应先持久化，重启可继续本地检查；每一个缺失用量的新调用都需要再次确认。
- 卡片/详情常显入口，已有演示直接打开；授权面板可展开资料和预算；引用、版本、源码本地修改与离线 ZIP 导出；生成失败保留旧演示。无需在正常流程填写框架或组件名。
- MCP 本地准备与源码候选提交；Agent 无法创建付费授权或启用候选。输出 zip 默认不带来源摘录，包含可信运行时、源码、许可与 NOTICE。

## 运行

在本开发目录先执行 `bash scripts/setup.sh`（安装依赖并构建可信运行时）。可双击 `启动 CardSpace v0.4.command`，使用独立的 CardSpace-v04 数据目录与 8766 端口。

开发验收预览使用 `output/v04-preview-data`，只放三张合成教学卡片，没有拷贝用户知识库。当前预览 http://127.0.0.1:8766/ 。重新启动此预览：

```bash
CARDSPACE_DATA_DIR="$PWD/output/v04-preview-data" CARDSPACE_PORT=8766 npm start
```

正常新版使用独立目录：

```bash
CARDSPACE_DATA_DIR="$HOME/Library/Application Support/CardSpace-v04" CARDSPACE_PORT=8766 npm start
```

生产目录中不要直接启动新旧两个 API；需要迁移真实数据时，先在旧版界面备份，再在独立新版目录恢复。迁移前副本为 `pre-v04-*.sqlite3`，不要用旧版代码直接打开 schema 3 数据库。回滚软件时恢复 v0.3 的升级前备份。

## 验证与发布限制

当前自动化共 128 项通过（87 项 Python、12 项前端、29 项编译/运行时）；生产构建通过。自动化覆盖编译攻击、数值 oracle、流程和列表状态、伪造消息、授权、幂等、预算、取消、重启、缺失用量、哈希与旧库恢复。浏览器检查了排序变化、引用、流程、原型、360px 卡片布局和独立导出 HTML；截图与本地测试数据在被忽略的 `output/qa`。

真实模型的 24 主题评估和 5 位目标用户研究尚未进行。本次没有使用真实模型密钥或发起付费请求。另有本机 HTTP 假供应商集成测试，核对真实 HTTP 适配器发送的范围和输出限制，不连接外部模型。`evaluation-cases.json` 是后续冻结评估输入与人工 oracle 要求，不能将它称为已通过的模型评估。当前是可试用的实施版本，未声明达到 BLUEPRINT 全部正式发布门槛，不创建 v0.4.0 Release。

仅 generic OpenAI-compatible chat/completions 适配，usage/输出语义随供应商不同。未知调用保留预留额度，用户确认继续也不会抹掉先前额度；不足预算需结束任务并重新报价。无可靠 tokenizer，strict 模式不可用。

语义校验能发现非法程序、无效来源及无交互输出，不能证明教学关系正确。所有生成陈述与假设需用户核对。单次部分输出/供应商错误以诊断结束，不用任意脚本兜底。

运行时哈希绑定产物。开发期变更可信运行时后，旧产物需在源码面板本地重新编译为新版本；已导出的离线包保留自己的运行时。未实现任意社区组件动态加载、多卡合成或真实后端。
