# 实现覆盖与后续边界

基于 PRD 的 V0.3 可用闭环，不将全部远期规划标为已交付。

| 模块 | 本次已实现 | 后续扩展 |
|---|---|---|
| 捕获 | 统一入口、原始提交先保存、自动识别文字/JSON/分享链接/文件、ChatGPT / DeepSeek JSON、DeepSeek fragments 与公开链接、幂等导入、来源隔离 | 导出 ZIP 附件、网页摘录、浏览器扩展、自动增量同步 |
| 解析 | 角色、原始树节点、分支、历史问题、消息引用 | 模型连续追问分组、跨对话主题理解 |
| 卡片 | 瀑布流 / 列表、就地编辑、自动保存/草稿、字段人工接管、收藏、折叠视图设置、分页、可撤销归档 | 拖拽看板、AI 聊天、图谱 |
| 搜索 | FTS5、中文短词补充、问题优先、原文跳转、自动语义补充与失败回退、兼容 embedding / RRF | 生产标注集调优、ANN 与专门重排模型 |
| 优化 | 本地格式整理、配置式结构化 AI、外部 Agent 直接提交修订、审批、版本与恢复 | 事实补全专门 pipeline、局部采用编辑器 |
| 体检 | 手动 / 周期 / 导入触发、持久化队列、规则初筛与发现管理 | 证据驱动冲突核查、货币成本估算、独立 Worker 进程 |
| 知识库 | MD / TXT / PDF / DOCX、原始 BLOB、分块与定位、段落引用、当前卡片候选参考、另存笔记 | OCR、HTML 采集、多库隔离、文档版本影响分析 |
| Agent | API / stdio MCP、认证、权限分离、乐观锁、审计日志 | Streamable HTTP 安全桥接、远程授权 |
| 平台 | OS 数据目录、WAL 事务、v1→v2 字段保护迁移、自动 / 手动备份、哈希校验恢复 | 更多版本迁移、应用级加密、安装包与自动升级 |

AI 模型输出的结构与失败场景使用 mock 回归；没有用户自己的模型配置，不声称真实模型服务已联调。中文模糊查询使用字词重合，仅可作为初步召回，不等同于已达到 PRD Recall@5 指标。50–100 条真实标注集、固定硬件的 P95 压测、事实误改率与正式发布需要后续独立验收。

V0.2 增加 MIT 许可证、第三方归属、贡献与安全说明、Issue / PR 模板、来源扩展文档及排除用户数据的源码分发。首页移除横幅和统计块，低频导航折叠。


V0.3 落实「内容先行、自动填充、按需修正」：单一录入入口、失败就地反馈、只改一项、人工字段保护、撤销归档、折叠上下文与当前卡片引用候选。自动元信息仅涉及标题/摘要/已有主题，摘要必须能定位到原文连续片段。没有模型配置时使用规则；真实模型质量需要维护者自己的服务继续验收。
